# airline_big_data_project

## Етап налаштування
**Кожен учасник** Усі встановили Docker та перевірили його роботу.

* **Каріна та Віта:** Конфігурація `Dockerfile` для створення образу `my-spark-img`.
* **Софія:** Налаштування `main.py` як точки входу в застосунок.
* **Ліза:** Налаштування команд запуску контейнера.

## Етап видобування
**Кожен учасник:** Робота над спільним модулем зчитування даних.

* **Віта:** Створення відповідних схем для набору даних.
* **Ліза:** Реалізація логіки створення DataFrame шляхом зчитування розбитих на партиції файлів.
* **Каріна:** Створення окремого модуля та функцій для операції зчитування.
* **Софія:** Перевірка коректності зчитування (валідація схеми та кількості рядків).

## Етап попередньої обробки даних

* **Ліза:** Отримання загальної та статистичної інформації про числові ознаки.
* **Віта:** Приведення ознак до потрібного типу та видалення неінформативних полів.
* **Каріна:** Обробка пропущених значень та парсинг дати.
* **Софія:** Проведення аналізу на наявність дублікатів та їх видалення.

## Етап трансформації
**Кожен учасник:** Кожен учасник у своєму файлі реалізує **6 власних бізнес-питань** та аналізує план виконання.

## Етап запису результатів
**Кожен учасник:** Кожен учасник реалізує функцію запису своїх відповідей у `.csv`, налаштовує параметри запису та ігнорування результатів у `.gitignore`, координує структури вихідних папок `output/`, перевіряє коректність формату записаних файлів та виконує збір усіх планів у документацію проекту.
